# נו-שופ 🛍️

חנות מקוונת חכמה - בריאות טבעית, חקלאות ביתית, טכנולוגיה ועוד.

## פיצ'רים
- 8 דפים מלאים (בית, חנות, קטגוריות, עגלה, תשלום, אודות, צור קשר, אדמין)
- ממשק אדמין מלא: דשבורד, ניהול מוצרים (CRUD), הזמנות, לקוחות
- חיפוש חי, סינון, מיון, מועדפים, Quick View
- מצב כהה, RTL מלא, רספונסיבי
- localStorage לעגלה, מועדפים, מוצרים מותאמים
- **קניון שיתופי**: לכל מוכר חנות (שם, לוגו, טלפון, וואטסאפ, עיר, אתר, תיאור - מוצגים בפומבי) עם דף משלה (`/store.html?s=<slug>`), ומדריך חנויות (`/stores.html`). החנויות נגזרות ממוצרי המוכרים המאושרים לפי שם החנות; פרטי החנות נשמרים בדפדפן ומההגשה האחרונה של המוכר.
- **מכרו דרכנו** (`/sell.html`): הקהל פותח חנות ומעלה מוצרים לפי הקטגוריות הקבועות, מנהל החנות מאשר בפאנל (`/admin.html` → מוצרי מוכרים), החנות לוקחת 10% ממחיר המכירה. הסכם המוכר (`/contract.html`, מקור הטקסט ב-`js/contract.js`) מתקבל בחתימה אלקטרונית ונשמר לצד כל הגשה (גרסה, זמן, IP).
  - הנתונים נשמרים ב-Strapi המשותף (`community-backend/src/api/shop-seller-product`) דרך `api/seller-products.js`; אישור/דחייה דורשים חשבון "יוצאים לחירות" עם `app_role` של `super_admin` או `shop_admin`.
- **עריכת תוכן מתוך האתר (סופר-אדמין)**: כשמחובר חשבון עם `app_role` של `super_admin`, מופיע כפתור "עריכת האתר" בפינה. במצב עריכה כל טקסט ותמונה קבועים בדף (וגם התמונה הראשית של כל מוצר) מקבלים גלגל שיניים קטן: טקסט נערך במקומו בדף עם גודל, עובי, גובה שורה, צבע, יישור ומרווחים; תמונה - החלפה, גודל, יישור/מרכוז, מילוי ומוקד חיתוך, עיגול פינות ומרווחים; וגם הסתרה. "חזרה למקור" מוחק את הדריסה.
  - המימוש: `js/site-editor.js` (נטען אחרי `js/main.js` ולפני סקריפט הדף, כדי לצלם את ה-HTML הקבוע). הדריסות נשמרות ב-Strapi (`community-backend/src/api/shop-site-override`, מפתח = דף + נתיב האלמנט או `product:<id>`) דרך `api/site-content.js`, ומוחלות בכל טעינת דף; תמונות מוגשות מ-`/site-img/<documentId>` (`api/site-image.js`). אלמנט שה-JS של הדף ממלא דינמית (שם חנות, מונים) לא נערך.
