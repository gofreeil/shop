# נו-שופ 🛍️

חנות מקוונת חכמה - בריאות טבעית, חקלאות ביתית, טכנולוגיה ועוד.

## פיצ'רים
- 8 דפים מלאים (בית, חנות, קטגוריות, עגלה, תשלום, אודות, צור קשר, אדמין)
- ממשק אדמין מלא: דשבורד, ניהול מוצרים (CRUD), הזמנות, לקוחות
- חיפוש חי, סינון, מיון, מועדפים, Quick View
- מצב כהה, RTL מלא, רספונסיבי
- localStorage לעגלה, מועדפים, מוצרים מותאמים
- **קניון שיתופי**: לכל מוכר חנות (שם, לוגו, טלפון, וואטסאפ, עיר, אתר, תיאור - מוצגים בפומבי) עם דף משלה (`/store.html?s=<slug>`), ומדריך חנויות (`/stores.html`). דפי החנות הציבוריים נגזרים ממוצרי המוכרים המאושרים לפי שם החנות. רשומת החנות עצמה (פרטי החנות + פרטי המוכר + קבלת ההסכם) נשמרת בשלב פתיחת החנות: בדפדפן (`localStorage`, `js/seller-store.js`) תמיד, ובחשבון של משתמש מחובר ב-Strapi (`community-backend/src/api/shop-store`, רשומה אחת למשתמש, דרך `api/store.js`); חנות שנפתחה כאורח מסונכרנת לחשבון בכניסה הבאה.
- **פתח חנות** - זרימה בשני חלונות: (1) `/sell.html` - פותחים חנות: פרטי החנות, פרטי המוכר והסכם המוכר, פעם אחת; כשכבר יש חנות הדף מציג סיכום עם כפתור "העלאת מוצר" וטופס עריכה מקופל (`?edit=1` פותח אותו). (2) `/add-product.html` - מעלים מוצרים לפי הקטגוריות הקבועות (עד 6 תמונות, מחיר, תיאור); כל מוצר מעתיק מהחנות השמורה את פרטי החנות, המוכר וההסכם, וכאן גם "המוצרים שהגשתי". מנהל החנות מאשר בפאנל (`/admin.html` → מוצרי מוכרים), החנות לוקחת 10% ממחיר המכירה. הסכם המוכר (`/contract.html`, מקור הטקסט ב-`js/contract.js`) מתקבל בחתימה אלקטרונית עם פתיחת החנות ונשמר על רשומת החנות ולצד כל הגשה (גרסה, זמן, IP); שינוי גרסת ההסכם דורש אישור מחדש.
  - הנתונים נשמרים ב-Strapi המשותף (`community-backend/src/api/shop-seller-product`) דרך `api/seller-products.js`; אישור/דחייה דורשים חשבון "יוצאים לחירות" עם `app_role` של `super_admin` או `shop_admin`.
- **עריכת תוכן מתוך האתר (סופר-אדמין)**: כשמחובר חשבון עם `app_role` של `super_admin`, מופיע כפתור "עריכת האתר" בפינה. במצב עריכה כל טקסט ותמונה קבועים בדף, כל כרטיס מוצר (תמונה ראשית, שם, תיאור), כל כרטיס קטגוריה (תמונת באנר, מוקד חיתוך, שם, תיאור) וטקסט הבאנר "האתר בבנייה" מקבלים גלגל שיניים קטן: טקסט נערך במקומו בדף עם גודל, עובי, גובה שורה, צבע, יישור ומרווחים; תמונה - החלפה, גודל, יישור/מרכוז, מילוי ומוקד חיתוך, עיגול פינות ומרווחים; וגם הסתרה. "חזרה למקור" מוחק את הדריסה.
  - המימוש: `js/site-editor.js` (נטען אחרי `js/main.js` ולפני סקריפט הדף, כדי לצלם את ה-HTML הקבוע). הדריסות נשמרות ב-Strapi (`community-backend/src/api/shop-site-override`, מפתח = דף + נתיב האלמנט או `product:<id>`) דרך `api/site-content.js`, ומוחלות בכל טעינת דף; תמונות מוגשות מ-`/site-img/<documentId>` (`api/site-image.js`). אלמנט שה-JS של הדף ממלא דינמית (שם חנות, מונים) לא נערך. הדריסות נשמרות גם ב-localStorage ומוחלות סינכרונית בטעינה (לפני הרינדור של הדף) - בלי הבהוב של התוכן המקורי; דריסות גלובליות (מוצרים, קטגוריות, באנר) נשמרות עם page=`*` וחלות בכל הדפים.
